# 数学教辅 PDF 校对

生成一次性的本地 HTML 校对稿：左侧依次显示正文与答案原页并叠加定位框，右侧列出正文问题、答案问题和题答不一致。Codex 负责校对判断，本地脚本只负责 PDF 预处理和网页生成。不得调用 OpenAI API 或其他外部模型 API。

## 工作流程

1. 识别输入文件角色。优先依据文件名中的“正文、学生用书、练习册”和“答案、解析、参考答案”，再用封面、目录和前几页验证。若仍无法可靠判断，只询问一次。不要把页码相同视为正文与答案对应。
2. 支持三种输入：只有正文；正文和答案分别为两个 PDF；正文与答案合在同一个 PDF。保留源文件，不覆盖、不改写。
3. 分别预处理正文和可选答案：

   ```powershell
   python scripts/prepare_pdf.py --body "<正文.pdf>" --answer "<答案.pdf>" --work-dir "<工作目录>"
   ```

   只有正文时省略 `--answer`。正文和答案在同一 PDF 时只传 `--body`，在校对数据中按实际页码建立题答关系。
4. 阅读 `references/proofreading-rules.md`。结合 `manifest.json`、每页文字块和页面 PNG，依次完成正文校对、答案校对、题答一致性校对。文字提取只是辅助，页面图像才是版面、公式和图形的依据。
5. 正文与答案按章节、题型、例题号、练习号和小题号配对，不按 PDF 页码配对。无法可靠配对时标为疑似问题，说明“未找到可靠对应答案”，不得强行关联。
6. 按 `references/review-schema.md` 创建 UTF-8 `review.json`。每条批注使用 `targets` 指向一个或多个文档位置。长稿按 4-8 页一批检查，最终合并并连续编号。
7. 对能够明确定位的问题填写归一化 `bbox`；只能确定页码时设为 `null`，不得猜测坐标。
8. 运行：

   ```powershell
   python scripts/build_review.py --work-dir "<工作目录>" --review "<review.json>" --output "<输出目录>"
   ```

9. 检查脚本输出的计数，并打开 `index.html` 验证：正文与答案均显示、双文档批注可以分别跳转、定位框与原文对齐、筛选和缩放有效。每个文档至少抽查首页、中间页和末页。

## 判断边界

- 将有明确依据的错误标为 `confirmed`；合理但不能确定的问题标为 `suspected`；纯表达改进标为 `suggestion`。
- 公式、上下标、分式、根式、图形标注和扫描文字容易误识别。信息不足时降低确定性，并明确写出复核点。
- 同时核对题干、解析、图形和答案之间的一致性，但不要仅凭答案不同就断言原稿错误。
- 答案只有最终结果时，只检查可验证的一致性；不得虚构缺失的解题步骤。
- 一个问题横跨正文与答案时，在同一批注中放置两个 `targets`，并写明双方页码和题号。
- 不为了增加数量而生成批注。若未发现问题，可输出空问题列表。
- HTML 仅用于本次纸质誊红，不添加编辑、登录、数据库、稿件历史或“打开原稿 PDF”按钮。

## 输出

输出目录包含 `index.html`、`review-data.js`、按正文/答案分组的页面图片和静态资源。它可以复制到其他电脑直接查看；生成新的 AI 校对结果仍需在 Codex 中调用本 Skill。
