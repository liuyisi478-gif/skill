# 数学教辅 PDF 校对

Codex 做视觉识别、解题和编辑判断；脚本做渲染、精确算术、阶段封存、覆盖核对和 HTML 生成。不得调用外部模型 API。保留原 PDF 与双文档 HTML 结构，不重新排版原页。

开始读取 [阶段协议与格式](references/audit-protocol.md)、[校对规则](references/proofreading-rules.md)；批注沿用 [review-schema.md](references/review-schema.md)。

## 准备

用文件名、封面、目录验证正文/答案角色，不按 PDF 页码配对。支持正文单独、两个 PDF、同一 PDF 内正文和答案混排。只有无法可靠判断角色时才询问一次。

    python scripts/prepare_pdf.py --body "<正文.pdf>" --answer "<答案.pdf>" --work-dir "<工作目录>"

正文单独或合订本省略 --answer。生成 manifest.json、每页完整 PNG、文字及文字块。**渲染成功不等于模型看过图像**：用可用图像查看工具逐页打开 PNG，记录实际工具调用引用与原图 SHA256。扫描页空文本不能视为空白页；文字只供检索。无图像查看能力时保留未完成状态，不能进行扫描内容的数学判断。合订本先仅查看正文区域，具体答案识别推迟到独立答案封存后。

相同输入重跑复用预处理。PDF/倍率变化使用新工作目录，不覆盖历史记录。

## 六阶段

1. **识别与分题**：逐页清点正文，以能独立解答的小题为记录单位，保存章节、原题号、题干、题型、选项、图形条件、全部跨页区域、印刷页码和不确定项。不强制每题截图。页清单记录题号跳号/重复、跨页未闭合、疑似缺页；封面/空白页也不能漏。分数线、小数点、符号、单位回看局部，必要时提高分辨率，不猜数字。提交 inventory。答案识别属本阶段第二部分，但为避免污染，延迟到第2阶段全部持久化后。
2. **正文独立校对与解题**：使用仅含正文的 independent 任务包，3–5题一批；复杂图形或长题单题处理。检查文字、条件、图文、单位、歧义，使用合适年级的方法独立求解并保存简短过程。失败明确记录，不编答案。每批提交后生成封存的 independent_answers.json；全部题目（含失败）有记录后才能打开答案。独立答案不能在看过原稿答案后改写，AI 错误仅在复核中纠正。
3. **答案独立校对**：先识别答案原题号、逐步原文与结果，以章节/题型/小题/关键数据配对并提交 answer_inventory，无法匹配不强配。answer_audit 包不含 AI 独立答案，只提供已核实正文及原稿答案。逐步检查计算、条件、推理、单位、结论及年级方法；连等式拆到每个等号，正确结果不抵消中间错误。重要计算用 calc 或独立 Python 验算。仅结果时标 final_only，不虚构步骤。
4. **三方交叉核验**：comparison 包才同时提供正文、封存独立答案和原稿答案/步骤核查。脚本精确比较可解析的分数、小数、百分数与常数算式；未知表达、单位、开放解答需数学核验，不能字符串判错。记录答案与解析结论、过程与结论、图形与条件关系，核对空格数量。从答案末尾逆查正文，记录孤立答案、漏答、多答及栏目错配。AI 与原稿不同只是复核线索。
5. **疑难与冲突复核**：status 显示自动触发原因；对冲突、识别疑点、复杂图形、歧义、未证推断和步骤疑点生成 recheck 包。先重新查看双方原图，再用可靠工具验算或另一思路。更正转写保存在复核，不抹掉独立答案。只有原稿证据明确才标红；不能确认标黄；AI 错误且原稿正确时撤销原稿问题。正常简单题不重复多遍求解。
6. **HTML 输出**：export 从提交产物推导覆盖和批注。存在失败/缺阶段仅能 export --draft，明确显示未完成，再运行 build_review.py。红色确定错误、黄色待人工复核、蓝色建议。批注只保留位置/题号、类型、原文、改法及必要的一句依据；跨文档问题保留双方 targets。侧栏使用“清单 / 详情 / 答案”三个切换按钮，默认显示批注清单；点击“答案”在同一区域显示“正文精简答案”，答案与批注不同时占用高度。页码链接默认折叠。精简答案按正文题序仅显示题号、答案及必要状态，点击题号跳回原题；经过有效复核的 corrected_independent_answer 优先显示，待确认或缺失明确标记，不照抄原稿答案代替独立求解。详细封存答案、简短过程及逐题状态保留为折叠项，历史不覆盖。旧 review 仍能生成，但覆盖显示未知。

## 执行与续跑

所有命令的 --work-dir 指向预处理目录；完整记录格式见阶段协议。每次只执行一个包，提交成功后再生成下一个。

    python scripts/audit_run.py --work-dir "<工作目录>" packet inventory
    # 读取打印的任务包，实际执行后保存本批 UTF-8 结果，再提交：
    python scripts/audit_run.py --work-dir "<工作目录>" commit --packet "<包路径>" --result "<本批结果.json>"
    python scripts/audit_run.py --work-dir "<工作目录>" packet independent --ids "第一章-Q1" "第一章-Q2" "第一章-Q3"
    python scripts/audit_run.py --work-dir "<工作目录>" calc "1/3+0.2"
    python scripts/audit_run.py --work-dir "<工作目录>" status
    python scripts/audit_run.py --work-dir "<工作目录>" export
    python scripts/build_review.py --work-dir "<工作目录>" --review "<工作目录>/review.json" --output "<工作目录>/html" --html-file "<交付目录>/<稿件名>校对稿.html"

按六阶段顺序为其余阶段生成包、执行、提交。任务包只含当前任务需要的信息；全卷结构清点不等于全卷一次求解。续跑先读 status，默认分派未提交题；失败不冒充完成。重做分题或独立求解须新目录保留旧记录。

失败题在下游尚未使用结果前可只重试该题，保留失败收据，成功题不重跑；看过答案后不能重做独立解题。

脚本不能切换当前 Codex 的模型或推理额度，也不能证明模型实际看图或忘记先前看过的答案。若支持隔离上下文，第2、3阶段使用各自最小包；否则遵守封存顺序并披露同一上下文无法保证认知盲法。不要假装自动切换模型。无可得 token 数据记 usage:null；收据记录实际墙钟耗时。

## 交付标准

默认只向用户交付一个 `<稿件名>校对稿.html`，内嵌原页图像、批注和侧栏精简答案，可离线打开。最终回复只提供该 HTML 链接及必要的简短说明。JSON、收据、任务包、页面图像、文本和文件夹版网页留在工作目录，用于追踪和续跑；除非用户另行要求，不额外生成或交付 Markdown 报告、单独答案表、ZIP 包，也不把过程文件列为用户输出。

打开最终 HTML 抽查正文/答案首页、中页、末页、图形及跨页定位、多 targets 跳转、筛选、缩放、精简答案、复核更正及未完成状态。坐标不能确定用 bbox:null，不猜。不增加数据库、登录、历史管理或外部 API。
