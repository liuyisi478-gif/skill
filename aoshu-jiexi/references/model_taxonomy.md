# 题型归类词表（落到具体数学模型）

【题型归类】必须用下表中的具体模型名。禁止写"应用题""计算题""填空题""选择题"这类笼统标签。

## 一、三条书写规则

### 1. 一题可以有多个知识点

一道题同时考多个模型时，全部写出，用**全角加号**「＋」连接，**主模型在前**（主模型＝这题最核心、最能决定解法的那个），一般 1–3 个，最多 4 个。

```markdown
**【题型归类】** 环形跑道（追及）＋行程追及
**【题型归类】** 位值原理＋不定方程（整数解枚举）
```

判断标准：如果学生不会这个模型就做不出来，就该写进去；如果只是顺带用到的常识性运算（如"等差数列求和"里用到乘法），不必写。

### 2. 词表里有的 → 用原名；需要细分时加全角括号

```markdown
**【题型归类】** 抽屉原理（进一法）
**【题型归类】** 分数裂项（三个因数相乘）
```

括号里写的是**该题的特殊形态**，同一模型的不同形态要区分开（进一法和去尾法是两种完全不同的思路，不能都写"抽屉原理"）。括号内文字不参与词表匹配。

### 3. 词表里没有的 → 直接写，并在知识点后标注〔新拟〕

**遇到词表覆盖不到的知识点，不要硬套一个相近的旧名，也不要只写大类。** 按下面写法：

```markdown
**【题型归类】** 〔新拟〕最值·构造下界＋抽屉原理
```

- `〔新拟〕` 紧贴在该知识点**前面**（一个标签一个标记）
- 该题若还有其他新拟知识点，各自标注：`〔新拟〕A＋〔新拟〕B`
- 全卷末尾（"详解详析"全部题目之后）汇总一节，登记新增知识点，供后续并入本词表：

```markdown
## 新增知识点清单

| 知识点 | 判别特征 | 出处 | 建议归入 |
|---|---|---|---|
| 最值·构造下界 | 求"至少/最多"并需证明不能再少 | 三、第 5 题 | 组合与逻辑 |
| 提公因数配对 | 分子分母成倍数，整体约分 | 二、第 1 题 | 计算与数列 |
```

没有新增知识点时，**不写**这一节。

## 二、计算与数列

| 模型 | 判别特征 |
|---|---|
| 等差数列求和 | 相邻两项差相同，求总和 |
| 等差数列求项数 | 由首项、末项、公差反求项数 |
| 首尾配对（高斯求和） | 首末相加为定值，成对求和 |
| 等比数列 | 相邻两项比值相同（小学少用，多在找规律题） |
| 分数裂项 | 分母为相邻整数乘积、可拆成两个分数之差 |
| 分数裂项（三个因数） | 分母为三个连续（奇）数之积，系数为 $\frac{1}{4}$ 一类 |
| 巧算·凑整 | 通过加减凑成整十整百 |
| 巧算·提取公因数 | 多个乘法项含相同因数 |
| 巧算·倍数约分 | 分子分母成整体倍数关系，直接约分 |
| 繁分数化简 | 分数里套分数 |
| 循环小数化分数 | 给出循环节，要求化成分数 |
| 分数比大小 | 通分、交叉相乘、与中间量比较 |
| 定义新运算 | 用符号临时定义一种运算规则 |

## 三、数论

| 模型 | 判别特征 |
|---|---|
| 整除特征 | 判断或利用被 2/3/4/5/8/9/11 整除 |
| 位值原理 | 数字与数位的关系，如 $\overline{abc}=100a+10b+c$ |
| 数字谜 / 竖式谜 | 缺数字的算式，靠进位与位值反推 |
| 余数与同余 | 除以某数余几，周期性出现 |
| 尾数与末位周期 | 只问个位数字、末两位数字 |
| 质因数分解 | 求约数个数、最大公约数、最小公倍数 |
| 最大公约数与最小公倍数 | "同时""恰好""最少"等字样 |
| 约数个数与约数和 | 由质因数指数求和、求个数 |
| 完全平方数 | 平方后为整数，末尾数字与余数受限 |
| 完全平方数（余数分析） | 用"平方数除以 3/4/8/9 的余数受限"证不可能 |
| 奇偶性分析 | 用奇偶判断可行性、定范围 |
| 不定方程（整数解枚举） | 两个未知数一个方程，靠整除性缩范围 |
| 进制转换 | 出现"某进制"或非十进制记数 |
| 进位与退位分析 | 加法进位次数、减法退位次数 |

## 四、计数与组合

| 模型 | 判别特征 |
|---|---|
| 加法原理与乘法原理 | 分类相加、分步相乘 |
| 排列组合（枚举法） | 小学用树形图、有序枚举 |
| 组数问题（数字不重复） | 用给定数码组数，首位不能为 0 |
| 容斥原理 | "至少""都不""或"的重叠计数 |
| 容斥原理（三量） | 三个集合两两重叠，加减三次 |
| 抽屉原理 | "保证""至少有一个" |
| 抽屉原理（最不利原则） | 求"保证能做到"的最少次数 |
| 抽屉原理（进一法） | 总量÷每份容量，余数也要占一份 |
| 图形计数 | 数线段、三角形、长方形、正方形个数 |
| 标数法（路径计数） | 网格中从一点到另一点的走法数 |
| 握手问题 | 每两人一次，次数与人数关系 |
| 单循环赛与淘汰赛 | 场次与队数的换算，注意两种赛制不同 |
| 页码问题 | 数字个数与页码位数的换算 |

## 五、几何

| 模型 | 判别特征 |
|---|---|
| 一半模型 | 三角形与平行四边形等底等高 |
| 等高模型（共高） | 高相同，面积比等于底之比 |
| 鸟头模型（共角） | 两三角形有一组等角或补角 |
| 蝴蝶模型 | 梯形对角线分出的四个三角形 |
| 燕尾模型 | 三角形内一点连三顶点 |
| 等积变形 | 平行线间同底等高，面积不变 |
| 面积割补 | 不规则图形切开重拼成规则图形 |
| 面积差与平方差 | 两个正方形（或圆）的面积差，配成 $a^2-b^2$ |
| 平移与旋转拼图 | 把分散的段/块移到一起 |
| 圆与扇形 | 弧长、扇形面积、阴影部分 |
| 组合图形周长 | 线段平移合并，求周长 |
| 角度计算 | 三角形内角和、外角、平行线性质 |
| 立体图形表面积与体积 | 长方体、正方体、圆柱、圆锥 |
| 立体图形切割与拼接 | 切一刀增几个面、拼起来少几个面 |
| 染色与涂色面计数 | 小正方体拼大正方体，数涂色面个数 |
| 图形剪拼 | 剪一刀拼成指定图形 |
| 三视图与展开图 | 由视图或展开图还原立体图形 |

## 六、行程

| 模型 | 判别特征 |
|---|---|
| 行程相遇 | 相向而行，速度和 |
| 行程追及 | 同向而行，速度差 |
| 环形跑道（追及） | 同向绕圈，多跑一圈追上一次 |
| 环形跑道（相遇） | 反向绕圈，合跑一圈相遇一次 |
| 多次相遇 | 环形或直线往返，第 n 次相遇 |
| 流水行船 | 顺水逆水，水速影响 |
| 火车过桥 | 车长参与路程计算 |
| 火车错车 | 两列车相向/同向通过，路程为两车长之和/之差 |
| 钟表追及 | 分针追时针，角度差 |
| 电梯问题 | 人走＋梯动，类似流水行船 |
| 队伍行进 | 队伍长度参与路程，类似火车 |
| 变速与分段行程 | 中途改变速度，需分段计算 |
| 间隔发车 | 车速、发车间隔、相遇间隔三者关系 |

| 模型 | 判别特征 |
|---|---|
| 和差问题 | 已知和与差 |
| 和倍问题 | 已知和与倍数关系 |
| 差倍问题 | 已知差与倍数关系 |
| 鸡兔同笼 | 两种对象、两种脚数（可用假设法） |
| 盈亏问题 | 两次分配，一盈一亏 |
| 年龄问题 | 年龄差不变 |
| 植树问题 | 两端都栽 / 只栽一端 / 两端不栽 / 环形 |
| 方阵问题 | 实心/空心方阵，四周数量 |
| 工程问题 | 工作总量设为单位"1"，效率与时间 |
| 工程问题（合作与轮流） | 多人合作或交替工作 |
| 浓度问题 | 溶质、溶液、浓度三量 |
| 浓度问题（加水加盐） | 只改变溶剂或溶质，抓不变量 |
| 利润与折扣 | 成本、售价、利润率、打折 |
| 平均数问题 | 总量÷个数，基准数法 |

| 估算与取整 | 进一法、去尾法、四舍五入的实际取舍 |

## 八、组合与逻辑

| 模型 | 判别特征 |
|---|---|
| 逻辑推理（真假话） | 有人真有人假，假设法 |
| 逻辑推理（条件排除） | 多人多身份，用列表排除 |
| 最值问题（构造） | "至少""最多"，需构造＋下界 |
| 最值·构造下界 | 给出构造后还须证明不能再少 |
| 操作与游戏 | 取石子、翻杯子、移动火柴 |
| 操作不变性 | 找操作前后不变的数量（奇偶、染色、和） |
| 染色与覆盖 | 棋盘覆盖、染色论证 |
| 递推与数列建模 | 由题意得 $a_n=a_{n-1}+a_{n-2}$ 一类关系 |
| 周期问题 | 找循环节，用总数除以周期看余数 |
| 周期问题（数字串找规律） | 边加边写形成的长数字串，求某位或数字和 |
| 归纳与猜想 | 先算前几项，猜规律再验证 |
| 数阵图 | 填数使各行各列和相等 |
| 新定义题 | 题中临时定义概念，按规定操作 |
