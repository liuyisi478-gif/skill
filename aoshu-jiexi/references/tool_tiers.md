# 工具分档表（超纲检查依据）

本表约束学生稿；内部独立复核可用坐标、程序等工具，不能将内部方法直接复制给学生。用户指定年级、教材或允许工具时按用户要求调整。默认小升初奥数允许方程、比例，勾股定理须说明。丙档若出现在学生解法中须改写。

## 甲档：放心用（学生版可直接写）

- 四则运算、运算定律、分数小数百分数互化、繁分数
- 比与比例、按比例分配、正反比例、比例尺
- 份数法、单位"1"、归一归总、线段图
- 简易方程（一个未知数，ax±b=c、ax+bx=c 型）
- 假设法、鸡兔同笼式替换、盈亏比较
- 枚举、列表、树形图、加法与乘法原理
- 抽屉原理（含最不利原则）
- 整除特征、余数、质因数分解、位值原理、完全平方数
- 面积模型：割补、平移旋转、等积变形、鸟头、蝴蝶、燕尾、共角
- 等差数列通项与求和、周期问题
- 常用模型：牛吃草、工程三量、浓度、行程（相遇追及、环形、多次相遇、流水、火车过桥）

## 乙档：可用但须标明

用前在解析中标注"此处用到××"，由编辑决定去留。

- 二元一次方程组（消元、代入）
- 勾股定理（建议只在题目给出整数比 3-4-5、5-12-13 等，或图形本身已给出边长时使用）
- 容斥原理公式（两量、三量）
- 进制转换
- 位值展开式 abc = 100a+10b+c 的代数写法

## 丙档：禁用（出现即返工）

| 禁用工具 | 小学替代写法 |
|---|---|
| 平面直角坐标系、解析几何 | 割补、等积变形、线段图 |
| 三角函数、正弦定理 | 适龄几何推导、割补；题目未给的特殊角数值不能无依据直接给出 |
| 相似三角形符号体系（∽及未经讲解的相似定理） | 在适用条件成立时用沙漏、等高等底或份数推导；写出本题对象与比，不能仅更换术语掩盖超纲证明 |
| 同余式 a≡b(mod m) | "a 除以 m 余 b"的文字表述 |
| 组合数符号 C(n,k)、排列符号 A(n,k) | 树形图 + 乘法原理 + 有序枚举 |
| 不等式求解（移项、区间） | 逐一代入试算、排除法 |
| 函数、图象、定义域 | 列表找规律 |
| 根号与无理数运算 | 保留平方数形式，或题目直接给值 |
| 韦达定理、因式分解法解方程 | 不用；改用算术解法 |
| 集合符号 ∪ ∩、概率记号 P(A) | 韦恩图示意、文字描述 |

## 检查方法

逐条检查学生解法，使用丙档方法则改写，乙档加标注。原题给出的符号、单位、知识点名称不因词语命中就机械判为用了该方法。
