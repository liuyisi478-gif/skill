# 工具分档表（超纲检查依据）

小升初奥数允许使用方程、比例，偶发勾股定理。判断标准不是"是否超纲教材"，而是**该工具在小学奥数教学体系里是否教过、学生能否看懂**。分三档，丙档出现即返工。

## 甲档：放心用（学生版可直接写）

- 四则运算、运算定律、分数小数百分数互化、繁分数
- 比与比例、按比例分配、正反比例、比例尺
- 份数法、单位"1"、归一归总、线段图
- 简易方程（一个未知数，ax±b=c、ax+bx=c 型）
- 假设法、鸡兔同笼式替换、盈亏比较
- 枚举、列表、树形图、加法与乘法原理
- 抽屉原理（含最不利原则）
- 整除特征、余数、质因数分解、位值原理、完全平方数
- 面积模型：割补、平移旋转、等积变形、鸟头、蝴蝶、燕尾、共角
- 等差数列通项与求和、周期问题
- 常用模型：牛吃草、工程三量、浓度、行程（相遇追及、环形、多次相遇、流水、火车过桥）

## 乙档：可用但须标明

用前在解析中标注"此处用到××"，由编辑决定去留。

- 二元一次方程组（消元、代入）
- 勾股定理（建议只在题目给出整数比 3-4-5、5-12-13 等，或图形本身已给出边长时使用）
- 容斥原理公式（两量、三量）
- 进制转换
- 位值展开式 abc = 100a+10b+c 的代数写法

## 丙档：禁用（出现即返工）

| 禁用工具 | 小学替代写法 |
|---|---|
| 平面直角坐标系、解析几何 | 割补、等积变形、线段图 |
| 三角函数、正弦定理 | 特殊角直接给值，或图形割补 |
| 相似三角形符号体系（∽、对应边成比例） | 用"份数"表述、"面积比是边长比的平方"用倍数关系讲 |
| 同余式 a≡b(mod m) | "a 除以 m 余 b"的文字表述 |
| 组合数符号 C(n,k)、排列符号 A(n,k) | 树形图 + 乘法原理 + 有序枚举 |
| 不等式求解（移项、区间） | 逐一代入试算、排除法 |
| 函数、图象、定义域 | 列表找规律 |
| 根号与无理数运算 | 保留平方数形式，或题目直接给值 |
| 韦达定理、因式分解法解方程 | 不用；改用算术解法 |
| 集合符号 ∪ ∩、概率记号 P(A) | 韦恩图示意、文字描述 |

## 检查方法

写完解析后逐条扫描正文，命中丙档任一项 → 改写；命中乙档任一顶 → 加标注。
