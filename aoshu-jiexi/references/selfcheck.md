# 自检清单与常见错因库

Step 5 逐项过闸。任一项不通过，按标记规则降档，不得跳过。

## 闸一：读题（最高优先级）

- [ ] 题干数字是否逐个核对过？（尤其 0/6/8、1/7、3/5、小数点、分数上下标）
- [ ] 分数、比、百分号是否读对？"占""是""比…多/少"是否分清？
- [ ] 单位是否统一？（米/厘米、时/分、元/角）
- [ ] 图形：点的连线关系、垂直平行标记、已知角与长度是否全部用上？
- [ ] 图形比例是否与实际数据矛盾？（图上像直角不等于直角，须有标记或可算）
- [ ] 有没有条件未使用？有，通常说明读漏了题意。
- [ ] 有没有条件相互矛盾？有，立即标存疑，不硬解。

## 闸二：建模

- [ ] 选取的解法是否命中该题的核心结构（份数、行程三量、面积模型…）？
- [ ] 分类讨论是否穷尽？边界情形（重合、相切、端点在线上）是否单独处理？
- [ ] "至少/最多"型：是否既给出构造又证明了不可更优？只给构造即视为未完成。

## 闸三：计算

- [ ] 是否用 `scripts/verify.py` 做了穷举或模拟？
- [ ] 答案是否代回原题条件验算？
- [ ] 结果是否合理：整数性、奇偶性、整除性、数量级、是否在定义范围内？
- [ ] 中间结果是否用另一种算法抽查过至少一处？

## 闸四：表述

- [ ] 是否出现丙档工具（见 `tool_tiers.md`）？
- [ ] 是否出现"显然""易得""同理"等跳步词？
- [ ] 每一步是否写明依据（公式、性质、模型名）？
- [ ] 图形描述是否与学生看到的图一致？
- [ ] 字数是否符合 `format_spec.md`？

## 闸五：客户交付前自查（逐项核对，不输出该清单）

- [ ] 计算结果正确（关键数重算一遍）
- [ ] 选择题答案与选项字母对应一致；填空题最终值与所填空一致
- [ ] 计算题结果的符号、正负、单位、有效数字正确
- [ ] 快速对答案直接放在完整解析卷头：选择题为题号范围与字母串，填空逐题编号，末行提示查阅详解；题型行按本卷增减
- [ ] 未额外生成快速答案预览图、截图或独立预览文件（用户明确另行要求除外）；参考图只提供样式
- [ ] 每题正文首段以“题号.”开头，与首个栏目或答案同行；有“第X题”独立标题时也未漏掉正文题号
- [ ] 仅给原题型内容加题号，未为加题号新增或改名栏目；选择、填空用【解析】，计算、解答不加【解析】
- [ ] 计算题可直接写脱式或方程，不被强制要求“解：”；解答题保持“解：……／答：……”格式，思路分析按需添加
- [ ] 多空答案按空序用空格隔开，不用中文或英文分号；正文与快速答案表都已检查
- [ ] 填空题、选择题的答案与【解析】同一行、同一段紧接，无独立答案行或空段
- [ ] 每个有单位的算式结果均在公式外加全角括号单位；普通叙述与独立答句的单位不机械加括号
- [ ] 非口算计算题是完整的普通逐行脱式，含原式、中间步骤和最终结果，不用Markdown表格、HTML表格或代码块
- [ ] 脱式续行等号起始位置一致，Markdown硬换行有效；方程逐行书写
- [ ] 计算题【思路分析】位于对应题/小题标题下、脱式之前，不插入脱式中途
- [ ] 无跳步：公式、代换、编号连续
- [ ] 无"大概、可能、显然、易得"等模糊词；符号与题干一致
- [ ] 语言中性，无评价性措辞
- [ ] 每题都有【题型归类】，且落到具体模型（不是"应用题""计算题"）
- [ ] **一题考了多个模型时全部写出**，主模型在前，用「＋」连接
- [ ] **词表里没有的模型直接写出来并标 `〔新拟〕`**，没有硬套相近旧名、没有退回写大类
- [ ] 标了新拟的题，文末有 `## 新增知识点清单` 汇总（知识点 / 判别特征 / 出处 / 建议归入）
- [ ] 活动栏目位置正确：【思路分析】【题图分析】在答案前；【易错警示】【一题多解】在答案后
- [ ] 无对应情形不硬加栏目
- [ ] 【题目核查】只在真有问题时出现，且按"问题→影响→修正"三段式
- [ ] 解答题有独立的"答："行；口算题不写过程
- [ ] 多结论判断题逐项判断，无合并省略

## 常见错因库（按历史出错频率排序）

1. **读错数字**：扫描件中 6/8、1/7、3/5、小数点丢失。→ 复述题干时逐字比对。
2. **比例读反**：把"甲比乙多 1/5"当成"乙是甲的 1/5"。→ 用具体数字试算一遍。
3. **漏分类**：旋转、重合、点在延长线上等情形。→ 先画出所有可能的位置草图再动笔。
4. **只给构造不证最优**："至少"型题的经典失分点。→ 补下界论证。
5. **几何看错图**：误把某点当在共线上。→ 凡是"三点共线""某点在延长线上"，必须在题干复原里明确写出。
6. **单位陷阱**：时间与速度单位不匹配、元与角混用。
7. **多次相遇计数错**：把"第 n 次相遇"算成第 n 段时间。→ 用程序模拟验证。
8. **末位/周期题周期长度错**：周期不是想当然的 4 或 10，必须由程序检测最短循环节。
9. **面积模型比例错**：鸟头、蝴蝶模型的比对应错误。→ 用特殊值（如取具体边长）算一遍反验。
10. **答案与参考答案冲突时盲从**：先验算自己，再核对参考；参考答案也可能错，冲突必须标注。

## 冲突处理

若我的答案与给定参考答案不一致：
1. 重新走闸一、闸三；
2. 用程序或代回得到第三方结论；
3. 仍不一致 → 标 `存疑`，写明两种答案各自成立的条件，交由人工判定。禁止为迎合参考答案而改答案。
