# 输出格式规范（对齐《超详解解析要求》）

来源：用户提供的《超详解解析要求》+ 样例《2027SDFZ 入学数学真卷（一）答案.docx》。
交付物：Markdown 文件，公式一律行内 `$...$`，禁止 `$$`、`\[`、`\begin{}`。

## 一、整体结构

```markdown
# <卷名>

## 快速对答案
一、填空题　1. 10　2. 27　3. 90 …（只列客观题，用全角空格分隔）

## 详解详析
### 一、填空题
## 第 1 题
…
### 二、求值题
…
### 三、解答题
…
```

## 二、单题结构

### 1. 题目核查（仅当发现问题时输出，位于该题最前）

单独成段，固定三段式：**问题是什么 → 造成什么影响 → 怎么修正**。

- 题目无误：**不写**该栏目，直接给答案与解析
- 严禁顺着错误答案自圆其说、把错题硬讲通
- 关键条件缺失（图上确实看不清）：写明"缺失××条件，无法求解"，**不编造条件**

### 2. 按题型给出答案

| 题型 | 格式 |
|---|---|
| 填空题 | 单独一行写答案，如 `10`；多个空用空格隔开：`6 7`；一个空里多个数据用逗号：`3,4` |
| 选择题 | `1. A` 起头，紧跟【解析】 |
| 多结论判断题 | 对 A/B/C/D **各自独立**判断对错并给理由，不得只讲正确项、不得合并省略 |
| 口算题 | 只给答案，不写过程 |
| 混合运算 / 解方程 | 分步书写，**等号对齐**，每步只做一个运算，不跳步 |
| 操作题 | 文字描述作图要点：在哪取点、连哪条线、量多长 |
| 解答题 | `解：` 起，思路与过程融合，每步写明"这一步算的是什么"；最后**另起一行** `答：` |
| 逻辑推理 / 证明 | 层层推导，格式同解答题 |

### 3. 活动性栏目（按需添加，不为凑格式而加）

**位置硬性规定：**

- 【思路分析】【题图分析】→ 放在**答案之前**
- 【易错警示】【一题多解】→ 放在**答案之后**

**使用情形：**

| 栏目 | 何时加 | 写法 |
|---|---|---|
| 【思路分析】 | 压轴题、典型模型题、需先搭框架的题 | 用什么模型、为什么用、第一步先求什么；不抄题、不复述解析 |
| 【题图分析】 | 带图/图表的题（几何图、s-t 图、统计图、表格、线段图） | 图中能直接读出什么、图与条件怎么对应 |
| 【易错警示】 | 学生高频错题、易混点 | 点出错因与混淆点、给避免方法；**中性正向表述**，不写"错了就完蛋"这类话 |
| 【一题多解】 | 确有第二种适合小学生的解法 | 只补思路不同的第二种，不堆超纲法 |

### 4. 题型归类（每题必写，位于该题末尾）

必须落到**具体数学模型**，禁止写"应用题""计算题""填空题"。可选模型见 `model_taxonomy.md`。

**① 一题多个知识点时全部写出**，用全角「＋」连接，**主模型在前**，一般 1–3 个，最多 4 个：

```markdown
**【题型归类】** 环形跑道（追及）＋行程追及
```

**② 需要细分时用全角括号**补充该题的特殊形态（括号内容不参与词表匹配）：

```markdown
**【题型归类】** 抽屉原理（进一法）
```

**③ 词表里没有的知识点 → 直接写出来，并在该知识点前标 `〔新拟〕`。**
不要硬套一个相近的旧名，也不要退回写大类。同一题有多个新知识点时各自标注。

```markdown
**【题型归类】** 〔新拟〕最值·构造下界＋抽屉原理
```

**④ 全卷末尾汇总新增知识点**（没有新增则不写）：

```markdown
## 新增知识点清单

| 知识点 | 判别特征 | 出处 | 建议归入 |
|---|---|---|---|
| 最值·构造下界 | 求"至少/最多"并需证明不能再少 | 三、第 5 题 | 组合与逻辑 |
```

这一节的作用是让词表能持续变厚：每次写解析遇到新模型就登记进来，积累后并入 `model_taxonomy.md`，下一套卷子就不必再标"新拟"。

## 三、完整示例

```markdown
## 第 3 题

**90**

**【解析】** 火车通过大树所行路程就是车长，$640 \div 40=16$ （米/秒）；通过大桥所行路程是车长加桥长，$(640+800)\div 16=90$ （秒）。

**【易错警示】** 通过大桥时容易只算桥长而漏掉车长。记住：完全通过的行进路程等于车长加桥长。

**【题型归类】** 火车过桥
```

```markdown
## 第 11 题

**解：** 原式 $=1+3+5+\cdots+2027$

项数 $=(2027+1)\div 2=1014$ ，

原式 $=1014^2=1028196$ 。

**【思路分析】** 这是首项为 $1$ 、公差为 $2$ 的等差数列，用"首尾配对"或"项数平方"都能快速求和，先定项数再求和。

**【题型归类】** 等差数列求和
```

## 四、LaTeX 书写细则

| 场景 | 写法 |
|---|---|
| 分数 | `$\frac{3}{4}$` |
| 角 | `$\angle AOB$` |
| 度数 | `$45^\circ$` |
| 乘除 | `$\times$`、`$\div$` |
| 比 | `$3:4$` |
| 百分数 | `$25\%$` |
| 平行、垂直 | `$\parallel$`、`$\perp$` |
| 三角形、圆 | `$\triangle ABC$`、`$\odot O$` |
| 乘方 | `$12^2$` |
| 省略号 | `$\cdots$`（加法）、`$\dots$`（列举） |
| 面积单位 | 文字"平方厘米"，或 `$\mathrm{cm}^2$`，全篇统一 |

排版：公式与中文之间各留一个半角空格；公式内不写中文；不单独成行。

## 五、禁止项（lint 报 ERROR）

- 块级公式 `$$`、`\[`、`\]`、`\begin{}`
- `$` 不配对
- 模糊词：显然、易得、大概、可能、不难看出、同理可得
- 丙档工具（坐标、三角函数、同余符号、`C(n,k)`、不等式求解）
- 评价性措辞、负向引导
- 缺少【解析】或【题型归类】
- 【题型归类】写成"应用题""计算题""填空题"等大类（不是具体模型）

另有两类**不该判错、但必须提示**的情形（lint 报 WARN）：

- 知识点不在词表却未标 `〔新拟〕`——说明可能漏标，也可能该登记新模型
- 标了 `〔新拟〕` 但文末缺少「新增知识点清单」——新知识点会丢失，明天再遇到又得重标一遍
