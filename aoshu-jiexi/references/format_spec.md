# 输出格式规范（对齐《超详解解析要求》）

来源：用户提供的《超详解解析要求》+ 样例《2027SDFZ 入学数学真卷（一）答案.docx》。
交付物：Markdown 文件，公式一律行内 `$...$`，禁止 `$$`、`\[`、`\begin{}`。

## 一、整体结构

```markdown
# <卷名>

## 快速对答案

| 选择题 | **1～4　ACBD** |
|:---|:---|
| 填空题 | **5.** 6　**6.** 12 18 30　**7.** 100　**8.** $\frac83\pi$ |
| 解答题 | 请看下方“答案超详解”。 |

## 答案超详解
### 一、选择题
## 第 1 题
**1. A【解析】** ……
### 二、填空题
## 第 5 题
**5. 6【解析】** ……
…
### 三、解答题
## 第 9 题
9.解：……
…
```

卷头表中题号、题型顺序和答案须按本卷实际内容替换。没有某类题时省略对应行；填空较多时可在同一单元格内用 `<br>` 换行。同一道填空题的多个空用空格隔开，不用分号；不同题用明确题号区分。用户给的样图仅供版式参考，里面的答案不参与本卷求解。

表格直接放在正式完整解析内，除用户明确另行要求，不额外生成快速答案表的预览图、截图或独立预览文件。此规则不限制题目本身必要的几何配图。

## 二、单题结构

### 0. 正文题号

每道题正文的第一个段落以“题号.”起，题号与该段首个栏目或答案同行。独立的 `## 第 X 题` 标题可以保留作结构导航，但不能替代正文首段题号。题号只在大题开头标一次，多小题继续保留（1）（2）等小题标识。

**加题号只是给原题型内容加前缀，不是新增栏目的理由。** 【解析】用于选择题、填空题；计算题和解答题不添加【解析】。没有思路分析时，不为容纳题号硬加【思路分析】。计算题可直接在原式前加题号，随后逐行脱式；解答题可直接写“23.解：……”。

- 有思路分析：`**25.【思路分析】** ……`
- 无前置栏目，直接给填空答案：`**5. 6【解析】** ……`
- 有多个空：`**6. 12 18 30【解析】** ……`
- 直接写解答：`23.解：……`
- 有题目核查或题图分析：`**10.【题图分析】** ……`，之后正常给答案与解析，不重复添加大题号。

### 1. 题目核查（仅当发现问题时输出，位于该题最前）

单独成段，固定三段式：**问题是什么 → 造成什么影响 → 怎么修正**。

- 题目无误：**不写**该栏目，直接按对应题型写答案与过程，不统一添加【解析】
- 严禁顺着错误答案自圆其说、把错题硬讲通
- 关键条件缺失（图上确实看不清）：写明"缺失××条件，无法求解"，**不编造条件**

### 2. 按题型给出答案

| 题型 | 格式 |
|---|---|
| 填空题 | 无前置栏目时以题号起，如 `**5. 6【解析】** ……`；答案与【解析】同行紧接，多空按空序用空格隔开，不用中文或英文分号；一个空内有多个可取值时用逗号或“或”区分；答案后不换行、不另起段 |
| 选择题 | 无前置栏目时以题号起，如 `**1. C【解析】** ……`；有前置栏目则在该首个栏目之前标题号，答案字母仍紧接【解析】，答案和解析之间不换行 |
| 多结论判断题 | 对 A/B/C/D **各自独立**判断对错并给理由，不得只讲正确项、不得合并省略 |
| 口算题 | 题号后只给答案，不写过程、不加【解析】 |
| 混合运算 / 解方程 | 题号后直接写普通逐行脱式或方程步骤，保留原式、中间步骤和最终结果；需要思路时，先写“题号.【思路分析】”；不加【解析】，也不强制添加“解：”；续行等号位置一致，禁止用表格、代码块或LaTeX环境承载过程 |
| 操作题 | 文字描述作图要点：在哪取点、连哪条线、量多长 |
| 解答题 | 无前置栏目时以 `23.解：` 起；有前置栏目时题号放在该首个栏目之前，过程以 `解：` 起；不加【解析】，每步写明依据，最后**另起一行** `答：` |
| 逻辑推理 / 证明 | 层层推导，格式同解答题 |

### 2.1 算式单位

- 算式结果后必须写全角括号单位，且单位在公式外：`$12\times3=36$（平方厘米）`、`$180\div3=60$（千米/时）`。不能写成 `$12\times3=36$ 平方厘米`。
- 连续几个算式若结果均为有单位的量，分别标出各自的括号单位，不只给最后一个补单位。
- 已知量的叙述如“长12厘米”和独立答句如“答：面积为36平方厘米。”正常写单位，无须加括号。答句若仍含完整算式，算式结果单位仍按上一条处理。
- 无单位的纯数、比、百分数、倍数不强加单位；角度符号按原式保留。

### 2.2 脱式与小题思路的位置

- 非口算计算题给出完整、标准脱式，不能只列答案，也不能把全部步骤压成一串等号；不跳过必要的通分、代换或运算步骤。
- 一行一步；Markdown行末用两个空格形成硬换行。每行用单个 `$...$` 包裹，正常独立公式行是允许的，不用 `$$`、`\[`、`\begin{}`。
- 不用Markdown表格、HTML表格或代码块排计算过程；不为对齐等号改用表格。此限制不禁止统计数据表、分类枚举表或文末知识点登记表。
- 【思路分析】放在相应题号或小题标题下面、脱式之前。脱式中途不插入思路段；口算仍只给答案。

### 3. 活动性栏目（按需添加，不为凑格式而加）

**位置硬性规定：**

- 【思路分析】【题图分析】→ 放在**答案之前**
- 【易错警示】【一题多解】→ 放在**答案之后**

**使用情形：**

| 栏目 | 何时加 | 写法 |
|---|---|---|
| 【思路分析】 | 压轴题、典型模型题、需先搭框架的题 | 用什么模型、为什么用、第一步先求什么；不抄题、不复述解析 |
| 【题图分析】 | 带图/图表的题（几何图、s-t 图、统计图、表格、线段图） | 图中能直接读出什么、图与条件怎么对应 |
| 【易错警示】 | 学生高频错题、易混点 | 点出错因与混淆点、给避免方法；**中性正向表述**，不写"错了就完蛋"这类话 |
| 【一题多解】 | 确有第二种适合小学生的解法 | 只补思路不同的第二种，不堆超纲法 |

### 4. 题型归类（每题必写，位于该题末尾）

必须落到**具体数学模型**，禁止写"应用题""计算题""填空题"。可选模型见 `model_taxonomy.md`。

**① 一题多个知识点时全部写出**，用全角「＋」连接，**主模型在前**，一般 1–3 个，最多 4 个：

```markdown
**【题型归类】** 环形跑道（追及）＋行程追及
```

**② 需要细分时用全角括号**补充该题的特殊形态（括号内容不参与词表匹配）：

```markdown
**【题型归类】** 抽屉原理（进一法）
```

**③ 词表里没有的知识点 → 直接写出来，并在该知识点前标 `〔新拟〕`。**
不要硬套一个相近的旧名，也不要退回写大类。同一题有多个新知识点时各自标注。

```markdown
**【题型归类】** 〔新拟〕最值·构造下界＋抽屉原理
```

**④ 全卷末尾汇总新增知识点**（没有新增则不写）：

```markdown
## 新增知识点清单

| 知识点 | 判别特征 | 出处 | 建议归入 |
|---|---|---|---|
| 最值·构造下界 | 求"至少/最多"并需证明不能再少 | 三、第 5 题 | 组合与逻辑 |
```

这一节的作用是让词表能持续变厚：每次写解析遇到新模型就登记进来，积累后并入 `model_taxonomy.md`，下一套卷子就不必再标"新拟"。

## 三、完整示例

填空题：

```markdown
## 第 3 题

**3. 90【解析】** 火车通过大树所行路程等于车长，速度为 $640\div40=16$（米/秒）；通过大桥时所行路程等于桥长加车长，用时为 $(640+800)\div16=90$（秒）。

**【易错警示】** 完全通过大桥时，行进路程等于桥长加车长。

**【题型归类】** 火车过桥
```

选择题：

```markdown
## 第 1 题

**1. C【解析】** 发芽数为 $50\times80\%+30\times100\%=70$（粒），发芽率为 $70\div80=87.5\%$，选C。

**【题型归类】** 平均数问题（加权平均）
```

计算题（代码围栏只用于本规范展示原始Markdown；实际交付去掉围栏，保留每个续行前一行末尾的两个空格）：

```markdown
## 第 11 题

### （1）

**11.【思路分析】** 第二项改写为含因数3.6的乘积，再提取公因数凑整。

$3.6\times98+36\times0.2$  
$=3.6\times98+3.6\times2$  
$=3.6\times(98+2)$  
$=3.6\times100$  
$=360$

**【题型归类】** 巧算·提取公因数
```

方程同样按普通行书写，不另加行首等号：

```markdown
## 第 12 题

**12.【思路分析】** 先合并含x的项，再利用等式性质求解。

$3.8x-0.5x=0.99$  
$3.3x=0.99$  
$x=0.99\div3.3$  
$x=0.3$

**【题型归类】** 〔新拟〕一元一次方程
```

示例中的新拟知识点，实际交付时须照常在卷末登记。

不需要思路分析的计算题，可以直接写原式和步骤：

```markdown
## 第 16 题（计算）

16.$\frac34+\frac18$  
$=\frac68+\frac18$  
$=\frac78$

**【题型归类】** 〔新拟〕分数加减法
```

解答题保持原有“解／答”格式，仅在最前面加题号：

```markdown
## 第 23 题

23.解：每份有 $24\div4=6$（本）。

答：每份有6本。

**【题型归类】** 归一归总
```

## 四、LaTeX 书写细则

| 场景 | 写法 |
|---|---|
| 分数 | `$\frac{3}{4}$` |
| 角 | `$\angle AOB$` |
| 度数 | `$45^\circ$` |
| 乘除 | `$\times$`、`$\div$` |
| 比 | `$3:4$` |
| 百分数 | `$25\%$` |
| 平行、垂直 | `$\parallel$`、`$\perp$` |
| 三角形、圆 | `$\triangle ABC$`、`$\odot O$` |
| 乘方 | `$12^2$` |
| 省略号 | `$\cdots$`（加法）、`$\dots$`（列举） |
| 算式结果单位 | 公式外用全角括号，如 `$12\times3=36$（平方厘米）`；叙述句和独立答句正常写单位 |

排版：普通叙述中的公式与中文之间留一个半角空格；单位括号可直接紧接公式。公式内不写中文。脱式与方程允许独立逐行，使用单个 `$...$` 和Markdown硬换行；普通叙述公式仍尽量嵌入句子。

## 五、禁止项（lint 报 ERROR）

- 块级公式 `$$`、`\[`、`\]`、`\begin{}`
- `$` 不配对
- 填空题、选择题的答案与【解析】分行或分段
- 正文首段缺题号、题号与“第X题”标题不一致；不能只在独立标题标号
- 填空题答案部分使用中文或英文分号分隔各空（正文和快速答案表均适用）
- 已有“快速对答案”节却未用表格排写
- 算式结果后的单位未加全角括号
- 计算题用Markdown表格或HTML表格承载过程
- 模糊词：显然、易得、大概、可能、不难看出、同理可得
- 丙档工具（坐标、三角函数、同余符号、`C(n,k)`、不等式求解）
- 评价性措辞、负向引导
- 选择题、填空题缺少【解析】；计算题或解答题误加【解析】
- 解答题缺少“解：”（已有题目核查、暂不能求解的除外）；计算题不要求添加“解：”或【解析】
- 缺少【题型归类】
- 【题型归类】写成"应用题""计算题""填空题"等大类（不是具体模型）

另有两类**不该判错、但必须提示**的情形（lint 报 WARN）：

- 知识点不在词表却未标 `〔新拟〕`——说明可能漏标，也可能该登记新模型
- 标了 `〔新拟〕` 但文末缺少「新增知识点清单」——新知识点会丢失，明天再遇到又得重标一遍
