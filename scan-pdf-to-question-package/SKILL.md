# 奥数 PDF 转标准题库包

生成标准题库包 1.0。以 JSON 中的 Markdown、LaTeX 为主体，仅保留无法用文字和公式完整替代的必要插图。

## 开始前

1. 阅读 [references/standard-package.md](references/standard-package.md)。
2. 原始文件只读，中间文件和结果写入新的工作目录。
3. 清点正文 PDF 和答案 PDF。能明确配对时直接处理；文件对应关系不明确时只询问一次，不自行错配。

## 低消耗处理流程

1. 一套试卷建立一个 `source`；同一 ZIP 可以包含多套试卷。
   source.name 使用上传 PDF 文件名（不含扩展名），每道题重复写入同值 source_name。学校名从名称中去掉开头四位年份（可带“年”）和末尾卷号后提取，例如“2026年工大附中001”或“2026工大附中001”都得到“工大附中”；写入题源和每题的 school_name。无法可靠判断时填空字符串并列入待核对，不猜测。
2. 默认每次处理连续 2–4 页。每页只做一次主要视觉读取，在同一遍中确认题号、题干、公式、跨页关系、题型和是否含必要插图。
3. 扫描页渲染一次后复用。不要为纯文字题裁图，也不要制作单题截图、联系图或反复 OCR。同一处内容最多额外复核一次；仍不清楚就标记 `[待核对]`。
4. 把题干转成 Markdown，数学公式转成 LaTeX。记录原题号和 `source_pages`；跨页题合并为一条题目记录。
5. 按“必要插图”规则判断图片。只有确认需要图片时才裁剪一次局部原图；边界明显错误时最多修正一次，之后保留稍宽区域并列入待审核清单。
6. 每批题目合并关键词后，只运行一次 `scripts/find_knowledge.py` 查询候选知识点；不要把完整的 `knowledge_points.json` 读入模型上下文。知识点必须使用查询结果中的完整三级路径，不确定时留空。
7. 全部题目完成后执行一次纯文本一致性检查：题号是否连续、跨页题是否重复、答案是否错配、字段是否齐全。不要重新读取所有页面。
8. 生成 `manifest.json`，运行 `scripts/package_folder.py` 打包并校验。格式错误最多修正一次；内容仍不确定时保留待核对标记，不无限重试。

## 必要插图规则

以下内容通常需要保存局部原图：

- 几何图、统计图、函数或坐标图、图形规律、网格作图、立体图；
- 火柴、棋盘、钟表、路线等依赖图形关系的内容；
- 无法可靠转成 Markdown 表格的复杂表格或特殊排版。

以下内容通常不生成图片：

- 纯文字应用题；
- 能准确转成 LaTeX 的分数、方程、算式和公式；
- 能准确转成 Markdown 的简单表格。

图片只包含理解题目所需的原始插图，尽量不重复题号和题干文字。纯文字题的 `images` 必须为空数组。若一道题有多幅必要插图，按阅读顺序保存多张；图片路径与该题关联。

## 答案与解析

- 有答案 PDF 时，优先按原题号提取原答案和原解析，禁止用模型内容覆盖原资料。
- 原资料只有答案、没有解析时，保留原答案并生成简洁但步骤完整的解析。
- 没有答案 PDF，或答案 PDF 缺少对应题目时，直接根据完整清晰的题目生成答案和解析。
- 解析只写关键思路、必要算式和结论。数值题用代入、反算或程序复核；复杂题最多额外复核一次。
- 题干或插图缺少关键条件时不得猜测，答案和解析可以留空并列入待审核清单。
- 原答案疑似有误时保留原答案，在交付说明中标记“原答案疑似有误”，不要静默改写。

## 分类

- 每题填写题型、难度以及零个、一个或多个三级知识点。
- 难度统一按以下口径：基础为直接应用一个常规知识点；进阶为多步推理、变式或知识点组合；高阶为分类讨论、构造、复杂图形或关键突破不明显。
- 综合题允许多个知识点，但不为了凑标签而过度标注。

## 质量和安全

- 原始 PDF 不修改、不删除、不重命名、不覆盖。
- 可使用当前 Codex 会话处理用户已提供的文件；不要擅自调用额外的第三方 OCR、模型接口或付费服务。
- 文字和图片冲突时以原卷为准。所有模型生成答案解析导入后仍属于待审核内容。
- 标准 ZIP 可以包含原始正文 PDF；答案 PDF 仅作为提取来源，除非用户明确要求，否则不必放入 ZIP。

## 命令

```powershell
python scripts/find_knowledge.py "关键词1" "关键词2"
python scripts/package_folder.py <包目录> <输出.zip>
python scripts/validate_package.py <输出.zip>
```

## 交付

返回 ZIP 绝对路径，并报告题源数、题目数、实际保存的插图数、无图片的纯文字题数、校验错误和警告、模型生成答案解析的题号、原答案疑似有误题号及其他待核对题号。
